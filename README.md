# Tax Wise Website

Static HTML, CSS, and JavaScript website for the Tax Wise research project (R26-DS-004).

## Files
- `index.html` — all page sections and content
- `css/style.css` — layout and responsive styles
- `js/script.js` — navigation and demo form behaviour
- `documents/`, `presentations/`, `images/` — folders for approved project assets

## Preview locally
Open `index.html` in a web browser. No build step or package installation is required.

## Deploy on Vercel
Import this repository into Vercel with the **Other** framework preset. Keep Root Directory as `./` and leave Build Command, Output Directory, and Install Command blank. Vercel can serve the static `index.html` file directly.
